# CampusGo - сервис студенческих мероприятий

## О проекте
CampusGo — учебный проект. Он помогает студентам находить мероприятия колледжа и отправлять заявки на участие в одном месте, не листая десятки чатов.

## Проблема
Информация о мероприятиях размещается в разных чатах, поэтому студенты могут пропускать объявления, а организаторы не всегда знают точное число участников.

## Цель
Создать простой сайт со списком мероприятий и формой заявки.

## Основные функции первой версии (MVP)
- Просмотр списка мероприятий (дата, место).
- Просмотр карточки мероприятия (полное описание).
- Отправка заявки через форму.
- Проверка обязательных полей (валидация).
- Сообщение об успешной отправке.
- Поиск по названию и фильтр по дате (добавлено по запросу CR-01).

## Ограничения текущей версии (Технический долг)
- Данные мероприятий пока «зашиты» прямо в код.
- Заявки фактически не отправляются на сервер (нет бэкенда и базы данных).
- Проверка полей работает только на стороне клиента (браузера).
